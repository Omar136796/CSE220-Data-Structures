# CSE220 (Spring 2024) – Data Structures (BRAC University)

Lab assignments from CSE220, BRAC University's data structures course,
implemented in Python. Covers arrays, linked lists, stacks, recursion,
hash tables, and binary trees. All work was done in Google Colab, and
each notebook includes its output.

## Labs

| Lab | Topic | What's inside | Notebook |
|-----|-------|---------------|----------|
| 01 | Linear arrays | Insertion, removal, merging, and array-based problems | [Lab01_Linear_Arrays.ipynb](Lab01_Linear_Arrays.ipynb) |
| 02 | Multidimensional arrays | Zigzag walk, row rotation, knight moves, matrix compression | [Lab02_Multidimensional_Arrays.ipynb](Lab02_Multidimensional_Arrays.ipynb) |
| 03 | Singly linked lists | Traversal, removal, reversal, alternate merge | [Lab03_Singly_Linked_Lists.ipynb](Lab03_Singly_Linked_Lists.ipynb) |
| 04 | Doubly linked lists & stacks | Hospital waiting-room system (DLL), stack implementation | [Lab04_Doubly_Linked_Lists_and_Stacks.ipynb](Lab04_Doubly_Linked_Lists_and_Stacks.ipynb) |
| 05 | Recursion | nCr, prime check, base conversion, harmonic sum, recursive linked lists | [Lab05_Recursion.ipynb](Lab05_Recursion.ipynb) |
| 06 | Hashing | Hash tables with custom hash functions and collision handling | [Lab06_Hashing.ipynb](Lab06_Hashing.ipynb) |
| 07 | Binary trees | Mirroring, lowest common ancestor, inorder predecessor, tree sums | [Lab07_Trees.ipynb](Lab07_Trees.ipynb) |
| Mid | Lab mid-term | Stack-based card game simulation, NumPy seat assignment | [Lab_Mid.ipynb](Lab_Mid.ipynb) |
